# 兔不乖的提词器

一款原生 iOS 提词器，面向需要边录制边看稿、边读边跟读校准的内容创作者。支持 App 内录制，以及通过系统画中画（PiP）悬浮在系统相机之上使用。

> 本仓库为个人私有项目，与 PetLive 或任何组织仓库无关联。

## 主要功能

- **语音跟读**：使用系统语音识别追踪朗读进度，支持跳读、回读与识别会话重连后的进度校准。
- **画中画浮窗**：将提词内容作为系统 PiP 视频流显示，可切换到系统相机继续录制。
- **App 内录制**：提供前后相机切换、取景框和录像保存到相册。
- **即时阅读样式**：可在录制页调整字号、行距、文字透明度和镜像；提词线可以拖动到合适位置。
- **稿件管理**：支持输入、粘贴、文件导入、示例稿和本地历史稿件。
- **敏感词检测**：按平台口径进行本地扫描，支持替换建议与一键处理；稿件不会上传。
- **播放控制**：支持匀速、定时、倒计时、暂停、上一句和下一句。

## 如何使用

1. 打开 App，在首页进入当前稿件或新建稿件。
2. 在编辑页输入、粘贴或导入稿件；如需检查营销表达，先运行“敏感词检测”。
3. 回到首页，确认字数与预计时长；在“跟读设置”中选择语音跟随、匀速滚动或定时滚动，设置提词位置与倒计时。需要时在“拍摄”中选择相机取景和前置摄像头。
4. 进入跟读页后，可用“文字”调整字号、行距和透明度；用“左右翻转”“上下翻转”设置镜像，用“镜头翻转”切换前后摄像头。拖动粉色跟读线也能即时调整提词位置。
5. “上一句 / 开始录制 / 下一句”位于同一行；开始录制后，中央按钮切换为暂停或继续。底部“浮窗”可开启系统 PiP，切到系统相机继续看稿。跟读期间屏幕会自动保持常亮，结束后恢复系统设置。

## 开发环境

- Xcode 15 或更高版本
- iOS 15 或更高版本的真机（PiP、相机与语音识别需要真机权限）
- Swift Package Manager

```bash
swift test
open Prompter.xcodeproj
```

在 Xcode 中选择个人开发团队和已连接的 iPhone 后即可运行。请勿使用 PetLive 团队签名本项目。

## 隐私

- 稿件历史、敏感词扫描与阅读设置均保存在设备本地。
- 语音跟读调用 iOS 系统语音识别，需要用户授予麦克风与语音识别权限。
- 录像保存需要用户授予相册权限。

Assets.xcassets/        应用图标与陪读兔资源
design/                 录制工作台设计稿
